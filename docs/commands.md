# Commands

Everything in Lightbound can be set in the options window (`/lb`). These chat commands are shortcuts.

`/lightbound` and `/rfr` work everywhere `/lb` does. Commands only do something on a paladin.

## Windows

| Command | What it does |
| --- | --- |
| `/lb` | Opens or closes the options window. `/lb options` and `/lb config` do the same. |
| `/lb blessings` | Opens or closes the [Blessings window](features/blessings-window.html). `/lb bless`, `/lb raid` and `/lb assign` do the same. |

## Buffing and tanks

| Command | What it does |
| --- | --- |
| `/lb why` | Explains, for every group member, what the [buff key](features/buff-key.html) would cast next or why it skips them. |
| `/lb tank Name` | Marks a player as a tank, or unmarks them if they already are. See [Tanks](features/tanks.html). `/lb tanks` works too. |
| `/lb tank` | Lists the tanks, plus players who count as tanks for another reason (main tank, main assist, tank role). |

## Cleanse

| Command | What it does |
| --- | --- |
| `/lb ignore Debuff Name` | Adds a debuff to the [cleanse](features/cleanse.html) ignore list, or removes it if it's already there. Not case sensitive. |
| `/lb ignore` | Lists the ignored debuffs. |

## Frames

| Command | What it does |
| --- | --- |
| `/lb move` | Unlocks all frames so you can drag and resize them. Again to lock them. See [Quality of life](features/quality-of-life.html#moving-and-resizing-frames). |
| `/lb reset` | Puts every frame back in its default place and size. |
| `/lb grid` | Turns snapping to the grid on or off. `/lb snap` works too. |
| `/lb grid 30` | Sets the grid size (4 to 100) and turns snapping on. |
| `/lb minimap` | Shows or hides the minimap button. |
| `/lb unlock`, `/lb lock` | Unlock the frames, or lock them again. |
| `/lb explain` | Turns the explanations in tooltips on or off. |

## Warnings

| Command | What it does |
| --- | --- |
| `/lb toggle` | Turns the Righteous Fury warning on or off. |
| `/lb sound` | Turns the Righteous Fury warning sound on or off. |
| `/lb rfraid` | Turns the Righteous Fury warning in raids on or off. |
| `/lb world` | Turns the Righteous Fury warning in parties outside instances on or off. |
| `/lb seal` | Shows or hides the seal timer. |
| `/lb empty` | Turns the empty **NO SEAL** bar in combat on or off. |
| `/lb height 300` | Sets the seal bar height (60 to 600). |
| `/lb rested` | Turns the Well-Rested warning on or off. |
| `/lb fed` | Turns the Well Fed warning on or off. |

Type anything else after `/lb` (for example `/lb help`) to get a short list of commands in chat, with which switches are on or off.

The [buff key](features/buff-key.html) and the [cleanse key](features/cleanse.html) are not commands: set them on the **Buff key** and **Cleanse** pages of `/lb`.

## Without a space

Every `/lb` command also works as one word: `/lbrested`, `/lbmove`, `/lbgrid 30`, `/lbminimap` and so on.
